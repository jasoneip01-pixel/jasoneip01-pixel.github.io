## PGG考试概况

- 全称: 全国高校德语专业四级考试 (Prüfung für das Germanistik-Grundstudium)
- 主办: 教育部高校外语专业教学指导委员会德语分委员会
- 官网: http://pgg.sflep.com/
- 总分: 100%
- 五大板块: 听写(10%)→听力(20%)→阅读(20%)→语法词汇(35%)→写作(15%)
