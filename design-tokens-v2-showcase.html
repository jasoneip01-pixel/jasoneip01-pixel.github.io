Design Tokens v2

「温性现代主义学术风」— 从 80 页 HTML 作品中提炼的约束系统。
四个材质主题。6-12 色。衬线有魂。约束 = 品味。

三个铁律

  • ❌ 单页颜色 ≤ 12 种（含背景色变体）— 超过 = 失控
  • ❌ 内容型页面必须含至少一种衬线字体 — 系统字体 = 无魂
  • ❌ #6c5ce7 / #8B5CF6 / 装饰性渐变 — 禁用，AI 默认=人类审美拒绝

使用方式

  • ✅ 复制 design-tokens-v2-template.html，改 content 即可
  • ✅ 切换主题：改 <html data-theme="parchment|xuan|darkwood|slate">
  • ✅ 如需定制：在 <style> 中覆盖 CSS 变量，不写裸 hex
