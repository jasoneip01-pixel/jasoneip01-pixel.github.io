使用方式 两种

在任何 HTML 项目中引入 design-tokens.css，立刻获得全部 120+ CSS 自定义属性和基础组件。

现有项目引入

在 <head> 中引用 design-tokens.css，所有 token 立即可用。

<link rel="stylesheet"
  href="design-tokens.css">

定制覆盖

新项目从 Token 系统开始，覆盖需要变化的变量即可。

:root {
  /* 仅覆盖需要变化的 token */
  --clr-primary-700: #1e40af;
  --font-sans: "Inter",
    "Noto Sans SC", sans-serif;
}

设计原则 / Design Principles

极简

不做多余的东西。每个 token 都有明确用途，没有"看着好看"的变量。

干净

8px 基数间距，无随机偏移。色彩克制——冷灰蓝为主，暖橙为点缀。

克制

反模式编码约束——禁用紫/青渐变。组件集最小化，不追求完整 UI 框架。

2️⃣ 如何复用

新项目三步流程：

  1. 引用 token — <link rel="stylesheet" href="design-tokens.css">，立刻获得全部变量
  2. 查组件 — 在本页面找到对标的颜色/间距/组件样式，直接使用 token 名
  3. 找对标页面 — 从左侧参考表找到风格最接近的项目，复制 CSS 结构，替换 token 值

3️⃣ 如何贡献

新组件/新色板进 token 系统：

  1. 先在本页面确认是否已有对应 token
  2. 没有 → 加新变量到 design-tokens.css，不修改现有值
  3. 新组件模式出现 → 添加到本页对应章节
  4. 只加不减，不破旧页面

4️⃣ 品味基线

颜色主+辅+中性，最多 3 色。禁止紫色渐变
字体最多 2 种（展示+正文）。中文：Noto Serif SC / 系统默认（--font-serif 已入 token，可覆盖 --font-display）
装饰禁止 emoji 做图标。禁止无意义渐变
布局断点：640px / 768px / 1024px / 1440px（--breakpoint-sm/md/lg/xl）。8px 基数间距
动效transition 默认 300ms ease。动画不超过 1.5s

5️⃣ 工作流

新页面需求 → 群聊提需求 → 出 DESIGN.md 方案 → 审核通过 → 引用 token + 对标页面 + 生成 → 跑 check-contrast.py 过对比度门槛 → 推送上线
